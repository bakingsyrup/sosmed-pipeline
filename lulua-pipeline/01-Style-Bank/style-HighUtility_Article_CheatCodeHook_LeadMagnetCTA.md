### Mengotomatiskannya (Rekayasa Loop)

Semua yang kita lakukan sejauh ini masih mengharuskan kamu membuka Claude dan mengetik prompt. Kalau kamu ingin laporan data sepenuhnya otonom, bagian ini untukmu.

*Tugas Terjadwal*  
Misalnya kamu ingin laporan pasar kopi hijau setiap pagi pukul 07.00. Kamu bisa meminta Claude persis seperti itu.  
Cowork → Scheduled Tasks → New task. Buat tugas terjadwal, lampirkan proyek/folder kopi, dan tambahkan prompt yang ingin dijalankan Claude.  

Beberapa ide tugas terjadwal:  
• Analisis portofolio lengkap  
• Berita harian harga kopi arabika/robusta  
• Pergerakan stok semalam  
• Ide pembelian berdasarkan parameter yang ditetapkan  

*Rekayasa Loop & Goal*  
Kamu juga bisa menjalankan `/loop` & `/goal` bersama konektor GCD untuk mencapai target.

# Part 3: Master Universal Wireframe Blueprint (Elastic Narrative Phases)

---

**Phase 1: High-Stakes Hook & Agenda Tease**  
*Trigger: Curiosity + Authority + FOMO*  
**Role:** Grab attention with a bold “cheat code” promise, establish personal credibility, and preview the exact walkthrough steps (agenda list).  
**Core Components:**  
- Outcome statement: “In just a few minutes, you can turn [Tool] into your personal [Role]…”  
- Authority line: years of experience, daily personal usage, “wish I had discovered it sooner.”  
- Teaser menu: numbered bullet list of what the post will deliver.  
- Bridge to next phase: “Let’s get right into things:”  
*DYNAMIC CONTENT SCALING DIRECTIVE:* This is a fixed single-post phase. Use exactly one post with the hook + agenda. If the topic requires deeper authority building, embed a 1-sentence social proof sub-element (e.g., “used by X experts”).

---

**Phase 2: Foundational Infrastructure Setup (Tool/Data Integration)**  
*Trigger: Caution + Relief*  
**Role:** Establish the technical foundation step-by-step—connect the target tool to a live data source or key enablement service.  
**Core Components:**  
- Problem statement: without this, nothing else works.  
- Connector choice (name the service/tool; note if free/sponsored).  
- Step-by-step integration: path inside the tool (e.g., Connectors → Search → Connect).  
- “What you get” feature list (bullet points).  
- Pricing transparency & recommendation.  
- Critical pitfall warning with fix habit (e.g., verify logo in output).  
- Explicit prompt habit example.  
*DYNAMIC CONTENT SCALING DIRECTIVE:*  
- Minimum 1 post: combine all steps + warning.  
- Up to N/N posts (max 3): separate into “Connector walkthrough” (post 2.1), “Feature list + pricing” (2.2), and “Pitfall warning + fix” (2.3). Scale up if the tool has complex installation; scale down if trivial.

---

**Phase 3: Personal Memory/Context Layer Injection**  
*Trigger: Relief + Curiosity (teaser for automation)*  
**Role:** Build a context folder with hyper-personalised files so the AI gives tailored, strategy-aligned outputs.  
**Core Components:**  
- Folder creation: 5 file types (Profile, Strategy, Portfolio/Inventory, Watchlist, Saved Prompts).  
- Description of each file with examples of data to include.  
- Pro tip: ask the AI to auto-generate these files.  
- Teaser: “At the end I’ll share a guide that sets this up in 60 seconds.”  
- Bridge: “Stick around until the end…”  
*DYNAMIC CONTENT SCALING DIRECTIVE:*  
- Minimum 1 post: all 5 files + teaser in one message.  
- Up to N/N posts (max 5): one post per file type, plus teaser. Scale dynamically based on how niche/expert the personalisation layers are (e.g., complex strategy frameworks may need separate elaboration).

---

**Phase 4: Practical Use-Case Demonstrations**  
*Trigger: Excitement + Desire*  
**Role:** Show real-world prompt workflows and outputs—proving the system’s value and making it instantly actionable.  
**Core Components:**  
- Workspace setup (project + context folder attachment).  
- Core use-case 1: general overview/analysis with personalisation.  
- Core use-case 2: event-driven reporting (earnings, harvests, releases).  
- Core use-case 3: comparisons (products, assets, entities).  
- Additional prompt idea shower (brief).  
- Benefit reiteration: “takes <5 minutes to get started.”  
*DYNAMIC CONTENT SCALING DIRECTIVE:*  
- Minimum 1 post: batching all three use-cases into one showcase.  
- Up to N/N posts: expand each use-case into its own post (4.1, 4.2, 4.3). If domain has many distinct workflows, add a 4.4 “other prompt ideas” post. Scale based on user input data richness and tool capabilities.

---

**Phase 5: Automation & Loop Engineering**  
*Trigger: Power + Efficiency*  
**Role:** Elevate from manual prompting to fully autonomous reporting/research.  
**Core Components:**  
- Scheduled tasks: walkthrough (Cowork → Scheduled Tasks → New task).  
- Ideas for scheduled tasks (daily report, overnight moves, idea generation).  
- Loop & goal engineering: introduce `/loop` and `/goal` commands with a concrete example.  
*DYNAMIC CONTENT SCALING DIRECTIVE:*  
- Minimum 1 post: combine scheduled tasks + loops.  
- Up to N/N posts (max 2): separate scheduled tasks walkthrough (5.1) and loop/goal engineering (5.2). Scale based on whether advanced automation depth is needed.

---

**Phase 6: Advanced Optimisation & User Safety**  
*Trigger: Authority + Caution*  
**Role:** Show pro-level expansions (trade execution, dashboards, custom instructions) and impose a mandatory safety disclaimer.  
**Core Components:**  
- Trade/action execution via API (optional step).  
- Dashboards & vibe-coded visuals.  
- System prompts/instruction.md.  
- Safety admonishment: “always use your own judgment before letting AI execute anything.”  
*DYNAMIC CONTENT SCALING DIRECTIVE:*  
- Minimum 1 post: all tips + disclaimer.  
- Up to N/N posts (max 3): separate each advanced tip and end with safety disclaimer. Scale based on risk level of the domain—higher risk domains may need a dedicated safety post.

---

**Phase 7: Lead Magnet Conversion & Social Amplification**  
*Trigger: Reciprocity + Belonging*  
**Role:** Convert readers into subscribers/community members, encourage social sharing.  
**Core Components:**  
- Free guide/checklist offer tied to earlier teaser.  
- Two simple asks: subscribe to a newsletter, join a free WhatsApp/community.  
- Direct link (or clear call to action).  
- Follow & repost request.  
- Gratitude sign-off.  
*DYNAMIC CONTENT SCALING DIRECTIVE:* This phase is normally a single post. If the lead magnet requires explanation, it can expand into 2 posts (CTA + link). Otherwise, keep it as one tight closing post.
