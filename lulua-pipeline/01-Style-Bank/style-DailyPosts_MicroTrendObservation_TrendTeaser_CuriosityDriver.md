## Part 3: Master Universal Wireframe Blueprint

### Elastic Narrative Phases

#### Phase 1: Current Trend Snap & Momentum Signal
- **Purpose**: Hook scrolling audiences with a crisp, slightly informal observation that something is evolving fast—no exposition, just raw trend recognition.
- **Default Post Slots**: 1
- **Dynamic Content Scaling Directive**: If the drafting agent detects multiple supporting data points (e.g., recent market moves, user stats, viral anecdotes), expand to 2 posts: (1/N) observation headline, (2/N) the “why now” acceleration note.
- **Mandatory Copy Elements**:
  - One‑sentence opener using informal, forward‑moving language (e.g., “growing up fast”, “makin canggih”, “lagi berubah drastis”).
  - Zero explanation—pure signal.

#### Phase 2: Paradigm Jump Declaration
- **Purpose**: Contrast the old static model with the new dynamic one in a single, high‑impact line that feels like an insider’s glimpse into the future.
- **Default Post Slots**: 1
- **Dynamic Content Scaling Directive**: If the paradigm shift has multiple layers (technology, behavior, economics), split into 2 posts: (1/N) “dulu...” vs “sekarang...” contrast, (2/N) one tangible example of the new model in action.
- **Mandatory Copy Elements**:
  - A pivot phrase like “now we’re looking at the part where…” or “sekarang kita udah di tahap di mana…”.
  - A concrete behavior shift (“don’t just pay once, keep paying while work happens” → “nggak cuma bayar sekali, tapi terus bayar sambil kerjaan berjalan”).

#### Phase 3: Implication Tease & Soft CTA
- **Purpose**: Drop a single hint of what this shift enables or why it matters, then leave a curiosity gap that invites a click, swipe, or reply.
- **Default Post Slots**: 1
- **Dynamic Content Scaling Directive**: If the content format supports a direct link or sticker (IG story, Twitter card), render the CTA visually minimal. For pure text threads, attach a discreet “link in bio” or “swipe for details” prompt.
- **Mandatory Copy Elements**:
  - One short sentence implying a bigger story (e.g., “ini baru awal”, “mekanismenya bikin penasaran”, “liat cara kerjanya”).
  - An unobtrusive CTA line like “🔗 link di bio” or “▶️ swipe”.

**Overall Scaling Logic**: The drafting agent must first analyze the depth of the input topic—single anecdote vs. multi‑faceted industry shift. If the topic is lightweight, compress all phases into one tight post. If rich, expand each phase to 1‑2 posts, never exceeding 3 total for this archetype to preserve punch.
