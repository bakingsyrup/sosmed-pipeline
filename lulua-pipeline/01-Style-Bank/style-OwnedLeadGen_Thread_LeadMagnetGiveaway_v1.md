# Master Wireframe: Format 10 (LeadMagnetGiveaway)

> **Psychological Lever**: Reciprocal Gratitude & High Utility Lead Generation.  
> **Core Intent**: Offers a free high-value digital asset (Notion template, calculator spreadsheet, or research database) in exchange for a simple comment or opt-in.

---

## 📐 1. Elastic Narrative Rhythm

### 🔵 X (Twitter) Thread Rhythm (Dynamic 3 to N Posts)
* **Post 1 (Hook)**: Free asset giveaway announcement ("I built a free [Asset Name] for you").
* **Post 2..N (Asset Teardown)**: 1 feature breakdown per post showing dashboard screenshots and automations.
* **Final Post (Outro & Comment CTA)**: Direct comment prompt ("Comment '[KEYWORD]' below and I'll send you the free download link 👇").

### 🟣 Instagram Carousel Spec (Dynamic 3 to 15 Cards)
* **Card 1 (Cover)**: Headline ≤ 12w, Subhead ≤ 18w (Total ≤ 30w). Style C resource dashboard preview layout.
* **Cards 2..N (Feature Cards)**: Feature Header ≤ 6w, Tool capability ≤ 25w/block (Total ≤ 40w/card).
* **Card N (Outro)**: Keyword prompt ≤ 15w, Comment CTA ≤ 15w.

---

> ⚠️ **ANTI-BIAS DIRECTIVE FOR AI AGENTS**: The sample below uses N features purely for illustration. You MUST NOT default to 5 posts or 5 cards. Dynamically scale the output length (from 3 to 15 units) to fit the actual depth of the input source content!
