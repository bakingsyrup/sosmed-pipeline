## Part 3: Master Universal Wireframe Blueprint (Elastic Narrative Phases)

**Blueprint Name:** `Value_Dump_Thread_PromptList_Curiosity_ImmediateValue`  
**Archetype:** Numbered expert resource drop (list-based prompt/cheatsheet thread)

### Elastic Narrative Phases

#### Phase 1: The Big Promise & List Teaser (Hook)
- **Goal**: Instantly shock, spark curiosity, and signal massive value.
- **Structure**: A single post containing:
  - A high-impact result statement (past personal transformation).
  - A universal urgency/authority claim (“everyone NEEDS this”).
  - A numbered list title with an enticing quantifier (“10 insane X”).
- **Scaling**: Always exactly 1 post. However, if input data is extremely deep, an optional contextual “why now” sentence can be appended, but never a second full post.

#### Phase 2: Prerequisite Setup (Foundation)
- **Goal**: Remove friction by giving a quick, non‑negotiable setup step.
- **Structure**: 1 post clearly labeling the essential tool/connection/action, followed by a one‑line instruction (or pasteable command) that promises fast results (“<5 minutes”, “instantly”).
- **Scaling**: Dynamic from 1 to 2 posts if the domain genuinely requires two distinct foundational actions (e.g., install connector + create account). Else, strictly 1.
- **Bridge rule**: End with a phrase like “(crucial for all next steps)” to create continuity.

#### Phase 3: Core Value Drop Sequence (Numbered List)
- **Goal**: Deliver the promised value in a scannable, curiosity‑driven cascade.
- **Structure**: A series of numbered posts. Each post:
  - Starts with a benefit‑focused headline (action name).
  - Contains a one‑liner explaining the outcome (e.g., “teaches you how to…”).
  - Ends with either an implied action CTA (“If you send this prompt…”) or a pain‑relief hook.
- **Dynamic Content Scaling Directive** (for drafting agents):
  - Analyze input data depth first: count distinct, high‑value tactical items.
  - Minimum viable list: **2 posts** (if data is sparse, condense items into grouped mini‑lists within 2 posts).
  - Default sweet spot: **5–7 posts** (ideal for engagement).
  - Maximum: **10 posts**; if more than 10 items exist, curate only the top 10 and bury weaker ones in an optional bonus post.
  - IMPORTANT: Never hardcode `N=10`. Always output `N/N` ranges based on actual data, e.g., `Post 3/N–Post (N+1)/N`.

#### Phase 4: Bonus Escalation (Overdelivery)
- **Goal**: Create a “generosity spike” that compels saves.
- **Structure**: 1 post labeled “Bonus: [Quantity] ready‑to‑use [items]”. Briefly list the categories of what’s inside (e.g., “momentum indicators, trend detection…”).
- **Scaling**: Always 1 post, except when core value list is already at maximum (≥8 items) — then optionally merge bonus into the final core post as a “plus extra” sentence.

#### Phase 5: Engagement CTA & Loop Close
- **Goal**: Convert readers into saved/bookmarked assets.
- **Structure**: 1 post after the bonus (or after the last core item if no bonus) with a soft CTA: “Bookmark this for later”, “Share with a friend who needs this”, or a low‑friction follow prompt.
- **Scaling**: Always exactly 1 post.

### Elasticity Summary for Drafting Agent
- Start with Phase 1 (1 post).
- Phase 2: check if domain requires a short setup; produce 1 or 2 posts.
- Phase 3: audit the input material for discrete, high‑impact tips. Map these to a numbered list; output as `Post X/N` where N = total core posts (min 2, max 10).
- Phase 4: if core list lenght < 8, add a bonus post; else include small bonus in last core post.
- Phase 5: end with 1 CTA post.
- This blueprint naturally scales from **3 posts** (hook, 1 core tip, CTA) up to **15+ posts** (hook, 2 setups, 10 core, bonus, CTA).
