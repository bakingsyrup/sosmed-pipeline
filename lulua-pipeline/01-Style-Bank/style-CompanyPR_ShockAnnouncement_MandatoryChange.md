# Part 3: Master Universal Wireframe Blueprint (Elastic Narrative Phases)

**Archetype Phase Mapping: Executive Announcement – Mandatory Change**

### Phase 1: Attention‑Anchor Hook (Dynamic 1 post)
*   **Core:** Start with an arresting signal word(s) (`RAKSASA:`, `BREAKING:`, `00:00 GMT`) immediately followed by the subject + main action.
*   **Variable Slot Insertion:** Fill [Company/Maker], [Dramatic Change], and one concrete detail right in the opening sentence.
*   **Psychological Payload:** Shock, Exclusive‑Insider Knowledge, FOMO of being the last to know.
*   **Scaling Directive:** Always exactly 1 post. Never split the hook.

### Phase 2: Full‑Mandate & Scope Expansion (Adaptive 0‑to‑3 posts)
**Trigger:** Drafting agent first inspects the depth of available data (technical specifics, timeline, geographic scope, collateral impacts).
*   **Sub‑phase A (If data > 1 key detail):** “What exactly changes” – explain the mechanism, technology, or rule with 1‑2 concrete components.
*   **Sub‑phase B (If data includes rollout roadmap):** Timeline / geography granularity (dates, regions, models, products).
*   **Sub‑phase C (If data includes zero‑opt‑out or forced compliance element):** Statement of universality – who/what is NOT exempt, including edge cases.
*   **Format:** Each sub‑phase becomes exactly 1 post. If data sparse, skip all; if rich, publish up to 3 posts sequentially numbered `2/4`, `3/4`.

### Phase 3: Definitive Closing Statement (Dynamic 1 post)
*   **Core:** End the sequence with a stone‑cold, no‑loophole closure, avoiding any soft CTA. It may be a reaffirmation of the mandate or an implication that solidifies the shock.
*   **Variable Slot:** [Zero‑opt‑out wrapper] – phrase like “Tanpa terkecuali,” “No exceptions apply,” “Anda tidak bisa memilih keluar.”
*   **Scaling Directive:** Always exactly 1 post, regardless of Phase 2 expansion. This seals the narrative.
*   **Optional Thread‑closer:** If a subtle metric driver is desired, the closing line can be crafted as an unassailable truth that drives screenshots/shares, not as a “link in bio” prompt.

**Total Post Count Formula:** `1 (Phase 1) + (0 to 3) (Phase 2) + 1 (Phase 3) = 1 to 5 posts`. Drafting agent must produce the sequence with correct `(1/N)` numbering when N > 1.
