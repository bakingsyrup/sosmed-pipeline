# Master Wireframe: Format 4 (HistoricalPrecedent / Backtest Case Study)

> **Psychological Lever**: Data Proof & Historical Pattern Recognition.  
> **Core Intent**: Anchors today's market/business event against an exact historical cycle, past crisis, or backtest dataset to prove what happens next.

---

## 📐 1. Elastic Narrative Rhythm

### 🔵 X (Twitter) Thread Rhythm (Dynamic 3 to N Posts)
* **Post 1 (Hook)**: Historical comparison alert + quantitative metric delta ("The last time [Historical Benchmark] happened...").
* **Post 2 (The Unhedged / Past Outcome)**: Raw quantitative figures showing past results.
* **Post 3..N (The Hedged / Parallel Data)**: Comparative data breakdown showing how structured strategies protected capital.
* **Final Post (Outro & CTA)**: Comparative insight + [Owned Channel Handle] follow invite.

### 🟣 Instagram Carousel Spec (Dynamic 3 to 15 Cards)
* **Card 1 (Cover)**: Headline ≤ 12w, Subhead ≤ 18w (Total ≤ 30w). Style C cutout chart spotlight.
* **Cards 2..N (Data Cards)**: Data Header ≤ 6w, Metric comparison ≤ 25w/block (Total ≤ 40w/card).
* **Card N (Outro)**: Key Takeaway ≤ 15w, Follow CTA ≤ 15w.
