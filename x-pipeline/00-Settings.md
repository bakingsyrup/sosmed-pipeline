# Shinku Master Pipeline Settings

This file controls active workflow features and configurations for the Shinku pipeline. Changes made here or via the Ad Astra Sosmed Center UI take effect immediately.

- **YouTube Video Clipper**: Controls automatic searching, subtitle-scanning, and trimming of 30-60s `.mp4` video clips.
- **Glossary Automation**: Controls automatic extraction of technical terms and appending entries to master A-Z glossaries.
